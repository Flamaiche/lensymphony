# 🎵 LenSymphony

Bibliothèque **Java** de représentation et de synthèse musicale : notes,
silences, portées — jusqu'au rendu sonore.

![Java](https://img.shields.io/badge/Java-library-orange)

## Fonctionnalités

- Modélisation de pièces musicales (notes, silences, portées)
- Synthèse sonore d'instruments
- Lecture de fichiers XML
- Tests unitaires (JUnit) avec couverture 100 % sur les modules clés

## Lancer les tests

```bash
./gradlew test
